## Card 1: What Version Control Is

**Core Knowledge:**
Version control is a system that records changes to a file or set of files over time so that specific versions can be recalled later.

**Explanation:**
Version control systems track every modification made to files, creating a history that lets you go back to any previous state. While commonly used for software source code, the concept applies to nearly any type of file on a computer, including design files and layouts.

## Card 2: What Version Control Lets You Do

**Core Knowledge:**
A Version Control System allows reverting files or entire projects to previous states, comparing changes over time, and identifying who introduced a specific change and when.

**Explanation:**
VCS provides several practical capabilities: rolling back unwanted changes, comparing versions to see what changed, and tracing the origin of problems to a specific person and time. These features make it indispensable for collaborative work where multiple people modify the same files.
