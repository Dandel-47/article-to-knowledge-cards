## Card 1: Invention of the World Wide Web

**Core Knowledge:**
The World Wide Web was invented by Tim Berners-Lee in 1989 at CERN as a system for sharing information among researchers using hypertext links.

**Explanation:**
Berners-Lee's original proposal, "Information Management: A Proposal," described a hypertext-based system to help scientists share documents. The Web was not the same as the internet — it was an application built on top of existing internet infrastructure, designed specifically for information sharing.

Q: Where and when was the World Wide Web invented?

## Card 2: The First Website

**Core Knowledge:**
The first website was launched in 1991 at CERN, explaining what the Web was, how to get a browser, and how to set up a web server.

**Explanation:**
At this early stage, the Web was primarily a tool for scientists to share documents. The first website was simple and informational, serving as documentation for the Web itself. The Web did not start as a consumer platform — it began as a scientific collaboration tool.

**Example / Self-test:**
Q: What did the first website contain?

## Card 3: CERN's Public Domain Decision

**Core Knowledge:**
In 1993, CERN released the Web's underlying code into the public domain, allowing anyone to use, modify, and build upon the technology without paying royalties.

**Explanation:**
This decision removed all barriers to adoption and was instrumental in the Web's explosive growth. Had CERN kept the technology proprietary or charged licensing fees, the Web might never have achieved global adoption. This open release is one of the most consequential decisions in computing history.

**Example / Self-test:**
Q: Why was CERN's 1993 decision to release the Web's code into the public domain so important?

## Card 4: Mosaic — The First Graphical Browser

**Core Knowledge:**
Mosaic, released in 1993 at the University of Illinois, was the first popular graphical web browser. It could display images alongside text, making the Web visually appealing.

**Explanation:**
Before Mosaic, the Web was text-only. By rendering images inline with text, Mosaic transformed the Web from a scientific tool into a visually engaging medium. Marc Andreessen, one of Mosaic's developers, later co-founded Netscape, which released the Netscape Navigator browser in 1994.

**Example / Self-test:**
Q: What capability made Mosaic different from earlier web browsers?

## Card 5: The Browser Wars

**Core Knowledge:**
The mid-1990s browser wars pitted Microsoft's Internet Explorer (integrated into Windows) against Netscape Navigator. Netscape lost the market share battle and was acquired by AOL in 1999.

**Explanation:**
Microsoft's decision to bundle Internet Explorer with Windows gave it an enormous distribution advantage that Netscape could not overcome. Though Netscape lost, its codebase was open-sourced and eventually became Mozilla Firefox, continuing the competitive browser ecosystem.

**Example / Self-test:**
Q: What advantage did Microsoft have over Netscape in the browser wars?

## Card 6: Web 2.0 — From Publishing to Participation

**Core Knowledge:**
In the early 2000s, "Web 2.0" marked a shift from static web pages to dynamic, user-generated content. Platforms like Wikipedia, Blogger, YouTube, and Facebook transformed users from content consumers into content creators.

**Explanation:**
Before Web 2.0, the Web was primarily a publishing medium where most users only read content produced by others. Web 2.0 platforms enabled participation — anyone could create and share content. This shift fundamentally changed how people interacted with the Web and with each other.

**Example / Self-test:**
Q: What is the key difference between the early Web and Web 2.0?

## Card 7: The Principle of an Open Web

**Core Knowledge:**
Tim Berners-Lee founded the W3C in 1994 to develop open standards and has consistently advocated for a free, open, and neutral Web — the principle of net neutrality.

**Explanation:**
Berners-Lee's vision is that the Web should not discriminate against any person, content, or application. The W3C develops open standards to ensure interoperability. Net neutrality — the idea that all internet traffic should be treated equally — remains an ongoing debate, reflecting the tension between openness and commercial interests.

Q: What does the principle of net neutrality mean?
